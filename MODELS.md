# Library models and references

Reviewed14 October2026 against the linked primary documentation. This is a distinction between distribution/ownership models, not a ranking or a claim that Contour has equivalent coverage, staffing, accessibility evidence or maintenance guarantees.

- **Contour** is an authored TypeScript/React package distributed as ESM JavaScript, declarations and CSS. Vite is tooling for fixtures/catalogues, not a requirement that consumers mount another Vite app. Public primitives/tokens and experimental optional entries remain versioned package contracts; applications own workflows and data.
- **Radix Primitives** provides unstyled React interaction primitives for building a design system. It is not a ready-made Contour visual theme. Its [official introduction](https://www.radix-ui.com/primitives/docs/overview/introduction) describes accessibility and composition priorities. Source/typed APIs do not make arbitrary adapters automatically interoperable.
- **shadcn/ui** describes a code distribution platform: its CLI distributes component source into the application, where the adopter owns modifications and update reconciliation. That differs from upgrading an npm component package. See the [official introduction](https://ui.shadcn.com/docs). The original research interpreted the spoken “ChatC” as shadcn/ui; that remains an assumption, not a separate verified product name.
- **Material UI** is an independent React implementation of Google's Material Design, with prebuilt components and customization. Google's design guidance and the MUI implementation are separate sources. The [MUI overview](https://mui.com/material-ui/getting-started/) and [repository](https://github.com/mui/material-ui) describe that relationship; adopting Material's principles does not require copying its visual identity or claiming all MUI X capabilities belong to the same core scope.
- **Salt** is J.P. Morgan's open-source React design system for financial services and other products. Its [official glossary](https://www.saltdesignsystem.com/salt/about/glossary) and [repository](https://github.com/jpmorganchase/salt-ds) establish an actual public implementation. Specific private firm themes, company product screens and business workflows are not thereby public reusable assets. Study task clarity, support matrices and contribution boundaries rather than copying a bank's product identity.
- **Polaris React** is now a deprecated archived implementation, rather than evidence of an actively maintained current React target. Its [official archive](https://github.com/Shopify/polaris-react-archive) and Shopify's [web-component migration guidance](https://shopify.dev/docs/apps/build/app-home/migrate-from-polaris-react) distinguish the older React contract from the current migration direction. An archived reference can explain a historical pattern but needs an explicit maintenance disposition before reuse.

Other company design websites can be useful visual/process references without proving an open-source implementation, redistribution license or reusable package. Check the actual repository/package, source license, notices, supported environment and version before adopting code/assets. Public screenshots or tokens are not blanket permission to redistribute a brand. This page does not copy upstream implementation or change Contour's MIT license.

The bounded Base UI/Radix+cmdk/React Aria decision, exact versions, licenses and measured tradeoffs remain in [FOUNDATION.md](FOUNDATION.md). Preserve that dated evidence instead of treating a competitor list as a reason to add dependencies. New controls still require a reusable contract and demonstrated need.
