# Public API and maturity register

Contract version: **0.3.0**, reviewed 12 October 2026. Export names and stylesheet APIs remain unchanged. Native refs and typed root/part props are added; state callbacks and default appearance remain compatible. These additions are absent from 0.2.1. See [composition contracts](COMPOSITION.md). This register inventories the public entry declarations and actual JavaScript module exports; a catalogue specimen is not automatically a package export. Source links target the matching release tag. The catalogue URLs are discovery links, not immutable versioned documentation; its displayed example version may differ.

Maintainer: [@abuzareal](https://github.com/abuzareal). Every row has the same named owner; there is no implied support team or response-time guarantee. See [architecture, scope and compatibility](CONTRACTS.md), [contributing](CONTRIBUTING.md) and [private security reporting](SECURITY.md).

## Status definitions

- **Stable (0.x):** the current documented contract is supported and changes require release notes and validation. This is not a 1.0 compatibility promise, full documentation coverage or proof of every state/browser.
- **Experimental:** supported only within the stated limits; interaction/scene APIs may change in an explicitly documented 0.x minor release. Existing users still receive migration instructions.
- **Legacy:** retained for existing editorial/personal-site integrations. It is not removed or formally deprecated by this register. Prefer application-owned identity/layout in new products.
- Types inherit their defining module's status. Type-only exports cannot be imported as runtime values. New 1.0 promotions require complete docs, relevant behavior/integration evidence and outside-use feedback.

## Validation evidence key

**D**: emitted `.d.ts` contract and TypeScript checks. **C**: core import and packed consumers, with selected component regressions. **N**: separate packed optional-peer/declaration/build fixtures. **P**: package/bootstrap and exact pinned Next fixture. **G**: selected graphics lifecycle/paused-resize browser checks. The source fixtures are [public API](https://github.com/abuzareal/contour-ui/blob/v0.3.0/tests/public-api.test.mjs), [component behavior](https://github.com/abuzareal/contour-ui/blob/v0.3.0/tests/components.test.mjs), [native dialog](https://github.com/abuzareal/contour-ui/blob/v0.3.0/tests/dialog.browser.mjs), [graphics lifecycle](https://github.com/abuzareal/contour-ui/blob/v0.3.0/tests/stage.browser.mjs), [React matrix](https://github.com/abuzareal/contour-ui/blob/v0.3.0/scripts/test-compat.mjs) and [Next](https://github.com/abuzareal/contour-ui/blob/v0.3.0/scripts/test-next.mjs).

These identify reproducible checks, not claims that every row has a dedicated behavioral test. In particular, declaration compilation is not runtime validation, passing Chromium/axe is not manual screen-reader verification, and no blanket WCAG or framework certification is claimed. Release gates must run against the candidate archive before publication.
