# Emitted prop reference and guide audit

The installed package's `.d.ts` files are the full typed API. [PUBLIC-API.md](PUBLIC-API.md) links each released symbol and defining source; [REFERENCE.md](REFERENCE.md) maps every public runtime/type/style entry to maintained guidance. Native inherited React attributes and generic overloads are not replaced by a hand-written short table.

## Generated metadata

[docs/prop-metadata.json](docs/prop-metadata.json) is extracted from emitted declarations for Checkbox, SelectField, ProgressBar, TextField, TextArea, Dialog, Tabs, ToastProvider, DropdownMenu, Combobox and Table. It preserves all call signatures, authored/inherited prop names and selected prop types/required flags. Source destructuring initializers supply explicit defaults; missing initializer is not evidence of false, empty string or a browser default. Dependent expressions remain expressions, not evaluated promises. Generic/inherited React types may be verbose; read their emitted declaration for the complete context.

Run `npm run check:reference` after build. It fails on removed documented props, changed types/defaults, reference targets and stale generated metadata. `node scripts/check-reference.mjs --write` updates only after reviewing the change. Human behavior, anatomy, form ownership, accessibility and unsupported combinations remain authored. This bounded generator avoids inventing defaults from optional TypeScript properties or flattening an overloaded component into a misleading universal schema. Other component pages remain PAGE promotion work; type discovery is not full-page coverage.

## Nine existing guides: current contract differences

The catalogue has its own installed release. Its older release-labelled guides must retain their original meaning until that consumer is upgraded. The current public library references below supplement them; they do not silently relabel old documentation as current.

| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Checkbox      | Native input ref and caller id; descriptions and errors merge with caller aria-describedby. indeterminate=false; application owns checked/mixed relationships. Native successful-control/reset behavior in FORMS.md.                                                                                                                   |

The historical nine-guide audit compares the old installed declarations with the current implementation, rather than overwriting older limits. Guide URLs/search and catalogue composition remain deferred. The public component-page contract in DOCS.md still applies before promoting a full page; a row here is a focused audit record, not a claim that every PAGE acceptance item is finished.

## Forms, anatomy and states

Native field refs target the actual input/select/textarea; Dialog targets dialog and Tabs targets its root div. ProgressBar and ToastProvider have no native ref contract. DropdownMenu exposes its trigger through triggerProps, not a root forwardRef. Labels, description IDs, aria-invalid, button types and successful controls must stay attached to the correct element. Error takes precedence over hint in Field; loading/service failure is separate application state.

Read [FORMS.md](FORMS.md), [COMPOSITION.md](COMPOSITION.md), [OVERLAYS.md](OVERLAYS.md), [COMBOBOX.md](COMBOBOX.md) and [RECIPES.md](RECIPES.md) for actual runnable sources, named/default state, form reset, keyboard/focus and optional parts. Styling and state selectors belong to STYLING.md; version-specific source and issue paths use the public reproduction. Long labels, disabled fields and both themes need final composition checks. RTL/forced-colors coverage is fixture-specific; manual assistive-technology support is recorded in SUPPORT.md rather than inferred from emitted types.
