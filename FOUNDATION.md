# Interaction foundation

Decision for the 0.6.0 candidate, evaluated 14 October 2026: use **Base UI 1.9.0** for the new single-select Combobox. Existing native controls, Contour overlays, public APIs and CSS remain owned by Contour. This is a bounded decision, not a migration of every component or a claim that one foundation is universally better.

## Comparison

The same published Contour 0.5.0 host, data, CSS, nested Popover and application-owned asynchronous search were exercised with React 18.3.1 and 19.3.0 in Chromium 153. The candidates were installed from npm archives with strict peers. Each fixture was server-rendered and hydrated; refs, form reset, native modal placement, nested dismissal, stale requests, disabled options, synthetic IME events, RTL and forced colors were checked. Query cancellation belongs to the common application fixture, not to any foundation.

Installed bytes include declarations and upstream components that are not necessarily downloaded by the browser. The comparison is not a zero-dependency or tree-shaking claim. The library's production size gate separately measures Button, forms, table and Combobox journeys from its packed artifact. Base UI's date-fns and timezone peers are optional and are not needed for Combobox. No second foundation or table engine becomes a core dependency.

## Ownership and limits

Contour exports a single-select string-ID API, typed native input/popup parts and its own semantic styling. Base UI owns collection navigation, active-descendant behavior and selection mechanics. Contour bridges that popup into its dismissal stack and modal/top-layer boundary. Its adapter also prevents the foundation's closed-Escape clear action so an enclosing Contour layer can dismiss without silently clearing the selected ID. Existing Dialog, SelectField and Popover contracts are not replaced with upstream types.

Stable IDs must be unique and nonempty. Labels may change or repeat. Filtering must not redefine identity. For remote search, the application retains the selected option separately from current results, cancels or ignores obsolete requests and validates its server data. An unresolved selected ID is visibly invalid and contributes an empty form value until resolved or changed; it is never invented as a valid choice. Disabled choices cannot be newly selected; disabled controls are omitted from form submission.

Automated checks do not establish VoiceOver/NVDA certification, physical IME composition, mobile keyboard behavior or all browser/assistive-technology combinations. Those remain manual release evidence gaps. A descendant popup must be tested with any third-party modal library before claiming interoperability.

## Upstream maintenance and licensing

The primary implementations are TypeScript/React with JavaScript distributions and declarations. Base UI has versioned release/migration notes and active 1.9 releases; pinning the adapter dependency makes upgrades reviewable. React Aria and Radix likewise have their own versioned releases. cmdk is a separate project with its own cadence; an older release alone does not prove it is unmaintained. Supported React peer ranges do not prove every framework or browser configuration.

Retain upstream copyright/license notices when redistributing their code. These packages retain their own licenses; Contour's authored code remains MIT. npm dependency packages include their upstream notices. We do not copy a foundation's source into Contour or claim its accessibility work as independent certification.

Local open-state axe inspection reports aria-hidden-focus on temporarily hidden background controls. Tab/Shift+Tab/outside-focus behavior must be considered alongside that static result; the raw finding remains recorded and manual AT review is pending. See COMBOBOX.md. The adapter uses the public virtual-anchor and collision-Rect extension points to keep fixed-position coordinates correct under inherited CSS zoom; it does not copy or patch upstream internals.

Contour also owns synchronous input activation to avoid an obsolete upstream touch-open timer reopening a selected/closed picker. Public event cancellation/propagation hooks preserve native document observers and caller Escape vetoes. These adapters are regression-tested without exposing upstream event types in Contour props.
