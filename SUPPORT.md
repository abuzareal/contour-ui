## Combobox correction and retained diagnostic

The initial 0.6.1 whole-document scan reproduced **aria-hidden-focus** (serious), **page-has-heading-one** and **region** (moderate best-practice findings) in Chromium and WebKit. The input-outside-popup composition used Base UI's Popup focus manager, which hid background content even with Root modal=false. The failed scans are retained as before-fix evidence.

Contour now composes Base UI's public Root, Input, Positioner, List and Item parts with its own **non-modal, labelled popup region**. The listbox shares the visible field label; the popup is hidden when closed. The public Root actions ref completes the immediate closing phase and restores controlled query text to the selected label. Selection, active-descendant navigation, native forms and positioning still use the pinned foundation. The enclosing Dialog remains responsible for modal focus containment. No ARIA is stripped, private upstream internals patched, or axe rule excluded. Whole-document open/closed scans and Tab/Shift+Tab journeys pass in Chromium and WebKit; the existing native-modal, iframe, touch, CSS zoom and form regressions also pass.

`npm run test:diagnostic:upstream` retains the unmodified Base UI 1.9.0 Popup reproduction, including its strict zero-violation assertion. It currently fails in both tested engines. This diagnostic exercises a composition Contour no longer ships; `test:qa` remains the mandatory strict gate for the actual Contour component. A dependency reproduction is not a manual AT result or a universal upstream defect claim. Manual VoiceOver/Safari and NVDA/Firefox reviews remain pending.

## Commands and evidence layers

- `npm test`: deterministic state/helpers/component/lifecycle behavior; no arbitrary coverage target.
- `npm run test:browser`: existing native dialog/forms/overlay/style/optional scene journeys in Chromium.
- `npm run test:qa`: production fixture, strict axe assertion, focus/forms/overlay journeys and a small visual baseline. Any finding in the shipped fixture produces a failing result. Set CONTOUR_QA_ENGINES=webkit or a comma-separated engine set to exercise other installed browsers; browser launch failures remain visible.
- `npm run test:compat`: the packed React/optional/source-declaration matrix and copied recipes, using one archive when CONTOUR_ARCHIVE is set.
- Exact Vite/Next starter, Next integration, size and registry checks have separate scripts in RELEASING.md. Passing build/types does not prove a browser/deployment.

Every result should name package/commit/archive, date, OS/browser/tool versions, checked components/states and passed/failed/skipped/blocked outcomes. Keep failed first-pass evidence, identify authored fixture corrections and rerun only affected work. A screenshot baseline cannot establish accessible names/announcements; axe cannot certify WCAG or physical AT. Important errors need persistent text and chart data needs meaningful text/table alternatives in their applications.
